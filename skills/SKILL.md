이 스킬은 서로 전혀 상관없는 두 가지(예: 세탁기 + 명상, 냉장고 + 일기장, 지하철 + 식물…)를 강제로 충돌시켜서 예상 못한 조합을 만들어냅니다.작동 방식 요약
시드 2개를 받거나 하나를 임의로 뽑음
각각의 속성·메커니즘·감정을 뽑아서 교차시킴
5개의 리믹스 아이디어를 뽑고
그중 가장 신박한 걸 표시 + 바로 프로토타입할 수 있는 작은 다음 단계까지 제안
추가로 references/constraints.md에 있는 랜덤 제약조건(오프라인만, 1만원 이하, 한 손으로만 사용 가능 등)을 걸어서 더 기묘하고 재미있는 방향으로 밀어줍니다.지금 바로 써보고 싶으면

“세탁기 + 명상으로 신박한 아이디어 내줘”

또는

“신박한 사이드 프로젝트 아이디어”

라고 해보세요.
